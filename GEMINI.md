**Project Name**: custom_pos_keyboard_shortcut

**Version**: 13.0.0.0

**Summary**: Adds configurable keyboard shortcuts and a three‑column layout to the Odoo POS, improving desktop cashier efficiency.

**Description**:
`custom_pos_keyboard_shortcut` enhances the Odoo Point of Sale interface with an extensible shortcut system, automatic focus management, and a help overlay. It implements a responsive three‑column layout, supports arrow‑key navigation, and provides a future‑proof foundation for additional shortcuts and configuration.
